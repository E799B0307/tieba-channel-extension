# 贴吧频道聊天室（精简版）

一个在浏览器里用的贴吧频道聊天工具，加载扩展并启动配套代理后，就能在贴吧网页旁边开一个侧边栏，查看和发送频道消息。

项目仓库与协作入口：[E799B0307/tieba-channel-extension](https://github.com/E799B0307/tieba-channel-extension)。完整安装包见仓库 Releases。

---

## 怎么用（三步）

### 第 1 步：加载扩展

下载之后，在浏览器的扩展处，点「加载已解压的扩展程序」，选中这个文件夹，就加载好扩展了。

**使用方法为：**

1. 打开 Chrome 或 Edge 浏览器
2. 在地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）回车
3. 打开右上角的「开发者模式」开关
4. 点左上角「加载已解压的扩展程序」
5. 选中这个文件夹，点确定

加载成功后，浏览器右上角工具栏会出现一个贴吧图标的按钮。

### 第 2 步：启动配套转发程序（重要，发消息必须）

这个扩展要发送消息，需要一个小的配套程序在后台跑着。**不用装任何软件**，直接双击运行即可：

1. 找到和这个文件夹放在一起的 `tieba-proxy.exe`
2. **双击运行它**
3. 会弹出一个黑色窗口，显示 `[proxy] 监听 ws://127.0.0.1:8765` 就说明成功了
4. **这个黑窗口不要关**，最小化放着就行

> 代理为原有的未签名 Windows 二进制，本仓库没有其源码。运行前请核对发布页 SHA-256 并自行确认来源可信，不要授予不必要的管理员权限。

### 第 3 步：登录贴吧并使用

1. 打开 `https://tieba.baidu.com`，用你的贴吧账号**登录**（扩展会自动读取你的登录状态）
2. 点浏览器工具栏的**插件图标**，右侧会弹出聊天侧边栏
3. 在侧边栏输入**吧名** → 点「查找」→ 选一个「吧频道」
4. 进入频道后就能看到消息了，在底部输入框打字 → 回车（或点「发送」）就能发消息

## 能做什么

| 功能 | 怎么用 |
|------|--------|
| 看消息 | 进入频道后自动显示，实时刷新 |
| 发消息 | 底部输入框打字，回车发送 |
| @ 别人 | 点输入框左边的 `@` 按钮，选人即可 |
| 表情 | 点 `@` 旁边的 `☺` 按钮选表情 |
| 回复别人 | 点某条消息，选「回复」 |
| 贴表情 | 点消息旁的笑脸加号；点已有表情可贴同款或取消自己的表情 |
| 查看贴表情的人 | 点表情旁的人数，支持加载更多 |
| 收藏表情 | 点图片按钮，打开当前账号在贴吧手机端收藏的表情；可刷新同步，选中后预览并点发送 |
| 上传图片 | 收藏表情面板里的“上传图片”可选择外部文件，也支持粘贴；预览后点发送。支持 PNG、JPEG、GIF、WebP，最大 8 MiB |
| 撤回消息 | 普通成员可撤回自己消息；具备频道管理权限时，他人消息旁也会显示管理撤回图标，点击后确认 |
| 入频道通知 | 不显示入频道提示、隐藏控制事件或无正文的系统占位通知 |

## 更新本地版本

修改后的版本为 `0.2.6-local`。到 `chrome://extensions`（Edge 为 `edge://extensions`），找到已加载的这个目录，点击扩展卡片的重新加载，再关闭并重新打开聊天侧边栏。侧边栏的“重新连接”不能替代重新加载扩展。新增了百度图片上传与表情图片站点权限，浏览器要求确认时请检查权限提示。

本版修正长连接中长消息 ID 丢失精度、迟到消息被刷新游标漏掉的问题。收到发送回执后等待 30 秒，仍未看到频道消息时会再读取一次；网络读取失败时继续等待。无法确认时提示先核对频道，不推断为限频或审核，也不会自动重发。

0.2.6 进一步修正入频道和发送请求的 `client_logid`：按客户端 `Message.getMicTime` 使用微秒，不再多乘 1000，并保证同一连接内唯一且不超过 JavaScript 安全整数范围。发送身份读取登录响应的 role；消息来源与安卓连接一致。入频道回执必须确认所选频道，否则停止发送并保留草稿。这些报文修正已通过模拟测试，真实账号是否恢复送达仍需实际验证。时间单位参考 [客户端 Message.java](https://github.com/n0099/open-tbclient/blob/7cd55773c530118a622de825afc1cc33175c3d4d/com/baidu/android/imsdk/request/Message.java)。

若侧栏已经更新、后台还停在旧版，新按钮会被旧后台报为“不支持的操作”。现在打开侧栏时会核对后台版本和操作列表；不一致时显示黄色更新提示，禁止将新操作交给旧后台。点提示里的“重新加载插件”即可更新，随后重新打开侧栏。存在未发送草稿或图片时会先确认是否清空。底部显示当前侧栏版本。

空系统消息在后台解析和侧栏展示两处过滤，兼容旧后台返回的无正文入房通知，包括 `content_body` 为字符串 `"{}"` 的情况；正常聊天和有正文的系统通知保留。

`tieba-proxy.exe` 仍需运行，本次未修改代理程序。完整安装包中的代理单独分发，不放入 Git 源码历史。

图片选择和预览不会上传，只有点击发送才上传；失败后保留待发送图片和文字草稿。图片与文字分别发送，发送图片不会清空文字草稿。普通成员仅能撤回自己的消息；管理员撤回权限从当前频道详情读取，每次撤回他人消息前重新查询，不能通过本地开关或昵称取得权限。受保护的管理成员消息按手机端权限规则处理。权限变化后可重新选择频道更新按钮。权限读取失败不影响正常聊天和撤回自己的消息。

收藏表情读取当前网页登录账号的手机端云收藏（爱心页签），不建立另外一份本地收藏库，不修改手机端收藏。默认最多缓存一分钟，刷新按钮直接重新读取；换账号即失效。收藏表情按原始图片地址发送，不转码动图，不重新上传；外部上传不会自动加入手机端收藏。未同步到贴吧云端、来源或尺寸无效的表情无法显示，会提示不可用数量。云接口报错时可重试，仍可使用“上传图片”。同步字段参考客户端的 [NewFaceSyncDownloadModel](https://github.com/n0099/open-tbclient/blob/7cd55773c530118a622de825afc1cc33175c3d4d/com/baidu/tieba/newfaceshop/NewFaceSyncDownloadModel.java) 和 [GetCloudFaceGroupMessage](https://github.com/n0099/open-tbclient/blob/7cd55773c530118a622de825afc1cc33175c3d4d/com/baidu/tieba/newfaceshop/message/GetCloudFaceGroupMessage.java)。

管理员撤回使用原消息作者的百度账号作为 `uid_to`，不使用当前管理员账号或 IM 连接编号；同时使用消息实际类型。请求被拒绝时显示错误；未收到撤回事件时保留原消息并提示结果未确认，不自动重试。服务端时间限制仍由贴吧决定。字段和权限规则参考客户端实现：[撤回请求](https://github.com/n0099/open-tbclient/blob/7cd55773c530118a622de825afc1cc33175c3d4d/com/baidu/tieba/z29.java)、[消息操作权限](https://github.com/n0099/open-tbclient/blob/7cd55773c530118a622de825afc1cc33175c3d4d/com/baidu/tieba/y29.java)。

接口字段参考公开发布包 [chrome-tieba-channel-extension 0.2.3](https://github.com/Lostlitus/chrome-tieba-channel-extension/releases/tag/0.2.3)，保留现有本地代理、文字回复和 @ 功能。新增按钮图标来自 Lucide，许可证见 `icons/lucide-LICENSE.txt`。

## 常见问题

**问：发消息没反应 / 提示连不上代理？**
答：确认第 2 步的 `tieba-proxy.exe` 黑窗口还开着。关了它就不能发消息了，双击重新打开即可。

**问：黑窗口一闪就关了？**
答：可能是端口被占用（之前已经开过一个）。按 `Ctrl + Shift + Esc` 打开任务管理器，找到 `tieba-proxy.exe` 结束掉，再重新双击。

**问：换了贴吧账号 / 显示"登录状态已变化"？**
答：点侧边栏顶部的「重新连接」按钮即可。

**问：这个安全吗？**
答：扩展只用你已登录的贴吧账号收发消息，不碰其他网站。转发程序只在你自己电脑上运行，把你的消息转发给贴吧官方服务器，不经过任何第三方。详见隐私说明。
